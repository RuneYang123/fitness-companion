# 饮食输出样例 · 基础版

编写备注（不输出给训练用户）：独立虚构的成年外食者，目标是兼顾减脂增肌，可接受奶蛋肉豆。份量仅示范表达，不是每个人的默认配额；具体沿用已收集条件和当前食量，遵循[共用规则](writing.md)。默认不要求称重，精细目标由用户选择后再展开。

先把三件事做好：每餐有蛋白来源、主食正常吃、午晚餐加够蔬菜。外卖优先肉不油炸、青菜少油、酱汁分开。

午晚餐可以先拿自己的手作个参照：约一到两拳熟主食、一到一掌半熟鱼肉、两拳蔬菜。手掌不算手指，肉量不含骨头；这是方便点餐的起点，不是固定配额。豆腐、奶、蛋的搭配另看实际份量，不与肉简单按掌数等量互换。吃后容易饿、训练没力气或份量明显不合适时再调整。

从下面挑着轮换，不用每样都吃：

- 主食：米饭、杂粮饭、原味燕麦、馒头、普通面条、玉米、蒸红薯。
- 蛋白来源：鱼、虾、去皮鸡腿、鸡胸、瘦猪肉、瘦牛肉、鸡蛋、豆腐、豆干。
- 蔬菜：青菜、西兰花、番茄、黄瓜、冬瓜、菌菇等。
- 奶和水果：纯牛奶、无添加糖酸奶；苹果、橙子、香蕉、猕猴桃等。
- 想解馋：奶茶、炸物、甜点可以偶尔选小份，不用安排放纵日，下一餐照常吃。

一日安排需要时可以这样展示：

| 餐次 | 大致怎么搭配 | 可以去哪点或买 |
|---|---|---|
| 早餐 | 一小碗原味燕麦＋一盒纯奶＋一两个鸡蛋，按实际包装和食量调整 | 便利店、超市、早餐店 |
| 午餐 | 一碗左右米饭＋一份肉量实在的鸡肉或鱼＋两样蔬菜，米饭按前述参照和食量调整 | 小碗菜、自选快餐；沙县门店有鸡腿饭和青菜时也可选，肉不足再补 |
| 晚餐 | 主食＋鱼肉或豆腐搭配蛋、奶等蛋白来源＋蔬菜 | 按当天能点到的菜轮换；不只吃一盒菜，也不照搬午餐份量给所有人 |
| 水果 | 一份完整水果，比如一个中等苹果或橙子；看大小和全天安排调整 | 水果店、超市 |

拿不准份量，可以把整份饭菜拍给我，尽量带上饭碗，旁边放把筷子或勺子作参照。有剩饭、酱汁没吃或另外喝了饮料，顺口说一句就行。我会先帮你大致看肉、菜、主食的搭配，再说最值得调整的一点；油量和热量无法单靠照片看准。

吃上一两周，再一起看体重趋势、饥饿和训练状态；愿意的话也可以记腰围。一直乏力或不舒服就早点反馈，不用等满两周，也不用每餐拍照打卡。

## 用户明确要定量计划时

本段为另一份虚构试用：普通成年男性，30岁、170cm、70kg，主要久坐，准备每周力量训练3次，兼顾增肌减脂，主要吃外卖；没有已知相关饮食限制。近期体重趋势未知，因此是试行估算，不是实测维持热量，也不保证形成固定热量缺口。只在用户需要定量安排时使用这种排版，不自动叠加前面的食物长列表，不照搬数值给新用户。

每天先按这个目标试行：

| 营养素 | 每日目标 |
|---|---:|
| 碳水化合物 | 约230g |
| 蛋白质 | 约130g |
| 脂肪 | 约60g |

合计约1980千卡。脂肪包含肉、蛋、奶、坚果和饭菜里的油，不是额外吃60g油。

燕麦按干重；米饭、肉、鱼和蔬菜按熟重，肉鱼去皮去骨，水果按可食部分计算。

| 餐次 | 推荐吃什么 | 外食怎么选 |
|---|---|---|
| 早餐 | 原味燕麦50g＋低脂纯牛奶300ml＋水煮蛋1个 | 超市或便利店买燕麦和牛奶，早餐店买鸡蛋 |
| 午餐 | 米饭250g＋鸡胸肉或去皮鸡腿肉150g＋蔬菜250g | 小碗菜、自选快餐；沙县门店有鸡腿饭和青菜时也可选，注意去骨后的实际肉量 |
| 晚餐 | 米饭200g＋清蒸鱼肉100g＋北豆腐100g＋蔬菜250g | 家常菜外卖，门店有的话选清蒸鱼、少油豆腐和青菜 |
| 两餐之间 | 苹果150g＋香蕉150g＋原味坚果15g | 水果可以分开吃，也可以挪到正餐 |

外卖备注少油、酱汁分开。这是接近目标的一日组合，实际会随食材、标签和用油变化，不保证精确达标，也不要求为了凑脂肪数额外加油。拿不准份量时可拍照反馈，只粗看搭配与份量；先吃一两周，再结合体重趋势、饥饿和训练状态调整。
