# 练三休一 · 健身房增肌示例

编写备注（不输出给训练用户）：本页演示编排形式，动作和训练量仍按当前用户条件调整。实际回复须从[教学索引](teaching-index.md)选匹配视频并另起一行；未匹配的给明确标注的通用B站搜索入口，不直接照搬缺少视频入口的示例表。

虚构展示：已有训练基础、熟悉下列动作且无相关限制的成年人。具体安排需按个人调整，遵循[共用规则](writing.md)。

按“推→拉→腿→休息”一直往下排，不用每到周一重新开始。一次大约55～85分钟，还没缓过来就多休一天。

**无热身不训练，无激活不训练。** 先按当天内容活动关节，下面写了具体动作和次数；从小幅度开始，舒服地做，不硬扳。

| 当天 | 具体准备 |
|---|---|
| 推 | 手臂前后绕环各8次、屈伸手肘8次、手腕轻柔绕环每方向8次，墙壁俯卧撑8次 |
| 拉 | 双臂前伸收回8次、屈伸手肘8次、手腕轻柔绕环每方向8次 |
| 腿 | 扶稳踝关节前移每侧8次、徒手深蹲8次、徒手髋铰链8次 |

表内第1项是激活准备，不计正式组，也不练累。轮到划船前轻重量8次；上斜卧推、推肩或罗马尼亚硬拉前，各补一组轻重量5～8次，按工作重量适当增加准备。

**训练清单。** 推胸、卧推、推肩、下拉、划船、深蹲和硬拉，组间休息2～3分钟，其他动作60～90秒。重量选到这组做完，动作不变形还能再做2～3次。

| 推日动作 | 组×次数 | 记住这一点 |
|---|---|---|
| 1. 激活：轻重量推胸 | 很轻8～10次，稍加重量5次 | 先把轨迹做顺，做完还有力气 |
| 2. 器械坐姿推胸 | 3×8～12 | 把手对齐胸中部，脚踩稳，推走再控制收回 |
| 3. 上斜哑铃卧推 | 2×8～12 | 左右同步下放，不扭身体 |
| 4. 坐姿哑铃推肩 | 2×8～12 | 不靠越来越大的挺腰顶重量 |
| 5. 哑铃侧平举 | 2×12～20 | 慢慢展开，不甩身体 |
| 6. 绳索三头下压 | 2×10～15 | 大臂相对稳定，伸直手肘 |

| 拉日动作 | 组×次数 | 记住这一点 |
|---|---|---|
| 1. 激活：轻重量下拉 | 很轻8～10次，稍加重量5次 | 先试握法和轨迹，不甩身体 |
| 2. 高位下拉 | 3×8～12 | 手肘往两侧下方走，不甩杆 |
| 3. 胸托坐姿收肘划船 | 3×8～12 | 手肘沿两侧向后，身体不前后摆 |
| 4. 反向蝴蝶机 | 2×12～20 | 调好座椅，轻重量平稳打开 |
| 5. 哑铃弯举 | 2×10～15 | 不靠挺腰甩起 |
| 6. 锤式弯举 | 2×10～15 | 手腕中立，慢慢放下 |

| 腿日动作 | 组×次数 | 记住这一点 |
|---|---|---|
| 1. 激活：轻负荷史密斯深蹲 | 最低合适负荷8次，稍加重量5次 | 调好安全挡位，空杆也要确认能控制 |
| 2. 熟悉的史密斯深蹲 | 3×8～12 | 安全挡位调好，全脚掌踩稳 |
| 3. 哑铃罗马尼亚硬拉 | 3×8～12 | 膝微弯，屁股向后，哑铃靠近身体 |
| 4. 器械腿弯举 | 2×10～15 | 调好垫位，控制还原 |
| 5. 器械腿屈伸 | 2×10～15 | 平稳抬放，不撞配重 |
| 6. 有支撑的双脚提踵 | 2×12～20 | 慢慢抬起放下，不弹跳 |
| 7. 死虫式 | 2×每侧6～10 | 躯干稳住，慢慢伸手腿并呼吸 |

休息日不补漏掉的训练。疼痛、麻木或异常无力时停止对应动作。

比如某个动作写8～12次，等每组都能稳稳做12次、还留点力气，下次再加最小一档重量。没必要每次都加。

今天时间少，推日先做推胸/侧平举/下压，拉日先做下拉/划船/弯举，腿日先做深蹲/硬拉/腿弯举。别为了赶完而省掉热身和必要休息；如果经常来不及，就把计划改短些。

练后一句话即可：“今天推日完成，推胸三组12/10/9次，第二个动作不太熟。”
