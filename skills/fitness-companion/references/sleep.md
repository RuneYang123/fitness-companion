# 睡眠与恢复 · 基础版

独立模块，用户问睡眠、作息、训练后恢复，或主动选择时进入。遵循[共用规则](writing.md)，不把睡眠直接当成缺某种补剂，也不强制每位用户填写睡眠问卷。核对日期2026-11-06。

## 先问清什么

沿用已知资料，首次只自然问一句：

“最近睡得怎么样？一般几点睡、几点起？”

用户说个大概即可，不先发问题列表，不要求区分上床、实际入睡、夜醒、持续时间和白天状态等全部细节。已有回答就直接总结已知情况；“几点睡”的意思不明确时不据此计算精确睡眠时长。

用户主动提到睡不着、夜醒或白天困等具体问题时，再顺着问最影响当前建议的一项。咖啡、午睡、训练时间、持续多久等按需要逐步了解，不作为人人必答的固定问卷。接受用户自己的描述，不先贴诊断；不清楚或未回答的内容保留未知。

## 给建议的顺序

先看是否有足够睡眠机会与现实可行的作息，再看咖啡因、环境、训练、饮食和压力；每次先改一两项。补剂或药物属于后续针对性判断，不先给购买清单。

| 用户遇到的情况 | 优先处理方向 | 不直接推断什么 |
|---|---|---|
| 工作、学习等导致睡眠时间不够 | 根据必须起床时间和现实限制，商量能留出的睡眠窗口；轮班者单独适配 | 不能靠补剂代替缺少的睡眠时间，不硬套所有人同一个早睡时刻 |
| 起床时间忽早忽晚，作息偏晚 | 先稳定可执行的起床时间，了解是否有时差或节律问题，再逐步调整；困了再上床 | 不把所有晚睡都当疾病，不用固定钟点强迫不困的人上床 |
| 躺下难入睡、睡前兴奋 | 查看晚间咖啡因、训练和活动；尝试短时间的安静放松、舒适暗静的卧室，并观察反应 | 不凭“很累却睡不着”诊断皮质醇高，不承诺某项习惯一定治好失眠 |
| 夜间经常醒 | 按实际情况了解饮酒、环境、疼痛、夜尿或呼吸相关表现，给相应处理方向 | 不一律归因缺镁或压力大 |
| 晚练后影响入睡 | 先核对练前咖啡因；确有影响时尝试调整训练时段、强度或结束后的安排 | 不统一禁止所有晚间运动，不为改善睡眠而无条件取消训练 |
| 白天很困，准备组也明显失控 | 当天训练可减量或顺延，优先恢复；关注是否持续或有异常症状 | 不靠更多咖啡因硬顶，也不要求用高强度有氧“促进恢复” |

健康作息和睡眠环境的方向参考[NHLBI失眠处理](https://www.nhlbi.nih.gov/health/insomnia/treatment)。上述分流与训练联动是项目的实践规则，不是固定医疗处方。睡眠机会不足、节律问题与长期失眠区分处理，不将睡眠习惯建议当作所有问题的完整治疗。

## 用户默认看到什么

先总结时间和睡眠情况，再给调整建议，默认顺序如下：

1. **睡眠情况小结**：按已知资料简短列出上床时间、大致实际入睡时间、起床时间，以及主要困扰；夜醒和白天状态在已提供或影响判断时补充。时间不清楚就写“还不清楚”，不为凑表格一次追问所有项目。
2. **时长说明**：上床到起床只能算睡眠窗口，不能直接当实际睡眠时长。实际入睡或夜醒时长未知时，不声称精确睡了几小时；时长来自用户估计或设备时注明来源，不把单晚记录推成长期规律。
3. **调整建议**：根据小结挑最相关的一两项，用小表或短句说明“先改什么、怎么做、观察什么”。如需要给建议作息，把“当前情况”和“建议目标”明确分开，目标结合用户必须起床时间与现实限制商量，不编造用户已经采用的入睡时刻。

普通回复保持简短，不默认发长篇睡眠科普或整套补剂。演示模板中的假设时间与真实用户记录分开，不写入个人档案。

如果睡眠已是本次所需的最后一个模块，仍只正常输出睡眠小结和少量建议，末尾自然提供选择：“还有哪一块不合适，我们可以先改那一块；或者先按这版执行，我再把完整清单整理给你。”不在这条睡眠回复里直接重发训练、饮食、补剂或作者长结尾。用户选择要最终清单后，再按[计划总清单](plan-summary.md)给清单及原文结语；用户要修改就先改，不能把睡眠资料回答当作已经选择清单。

可选的手动反馈只需一句，例如“昨晚大概几点睡、醒了几次、今天精神怎样”。可以先试几晚再回来说变化，不要求每天填表或设置提醒。用户愿意时才看已有的穿戴设备截图，不要求买设备，不用某晚的深睡比例、HRV或睡眠评分诊断疾病、激素或营养缺乏。主动写入文件或导出记录仍按共用规则取得用户选择；不替聊天平台承诺数据保留方式。

## 补剂与其他模块怎么衔接

有明确需求时才从[扩展候选的睡眠部分](supplement-options.md)查询褪黑素、镁、南非醉茄等各自的证据和限制，再回到[补剂模块](supplements.md)核对标签、重复成分、用药和实际用量。不因为进入本模块就自动安排任何一种。

具体成分可能没有足够证据、可能不适合用户，也可能需要专业评估。褪黑素不能作为所有睡眠问题的统一答案；镁不等于通用助眠药；不把多种睡眠成分拼成默认组合。当前已在用的医疗治疗不自行停换。

睡眠问题影响运动时，按[训练规则](training.md)协调减量、顺延与有氧；夜间饥饿、晚餐或饮酒等问题按实际需要衔接[饮食模块](nutrition.md)，不直接给所有人安排睡前加餐。

## 什么时候建议专业帮助

睡眠问题持续、明显影响白天生活时，说明值得就医评估；长期失眠的循证治疗包括失眠认知行为治疗（CBT-I），不能只靠继续叠加补剂。不要未经个别评估就安排严格睡眠限制或自行调药。[NHLBI失眠治疗](https://www.nhlbi.nih.gov/health/insomnia/treatment)

如果用户报告频繁大声打鼾、憋醒或被目击呼吸暂停，尤其伴白天明显困倦，建议评估呼吸相关睡眠问题，不凭聊天确诊；困倦影响驾驶时先避免疲劳驾驶。只在相关表现出现时说明，不向所有人附诊断清单。[NHLBI睡眠呼吸暂停表现](https://www.nhlbi.nih.gov/health/sleep-apnea/symptoms)
