# 补剂扩展候选与需求判断

按需资料，核对日期2026-11-05。用于用户问某成分、希望看更多备选，或反馈相关需求时检索。只含通用成分名称、适用问题和独立来源，不含个人付费方案的剂量、时间表、标记或身份资料。

## 先按人分层，再查成分

1. **必须**：已经确认需要处理的缺乏或明确医疗补充要求。没有就写暂无，不把某个产品预设为所有人必买。需要满足蛋白、维生素等营养需求，不等于必须通过粉剂或胶囊满足。
2. **可选**：当前目标、基础与条件下已经值得讨论，用户仍可不选。常见为有饮食缺口且图方便的蛋白粉，以及适合力量或短时高强度训练者的单水肌酸。
3. **特定情况再考虑**：当前不进入服用表；用户出现下列情境时，先问关键缺口，再核对相关证据与标签。有情境也不意味着所有对应成分均值得用，证据不足或不适合时可以建议不选。

三层是本项目的问答组织方式，不是官方成分分级。同一成分随个人情况改变位置。证据来自健康成人运动研究、特殊疾病用途或小样本睡眠研究时分别注明，不相互外推。

## 当前目标下常见的可选项

| 成分 | 什么时候值得讨论 | 不能默认承诺什么 |
|---|---|---|
| 乳清或其他蛋白粉 | 实际蛋白摄入有缺口，或外食、出差、食欲使普通食物不方便 | 不保证喝了就增肌，不必在饮食充足之外追加，不强制练后窗口；过敏和乳糖耐受按产品确认 |
| 单水肌酸 | 有规律的力量或短时高强度训练，适合且愿意持续使用 | 不直接燃脂，不把开始后的水分增重当增脂；已知肾脏问题、相关用药或专业限制先核对 |

来源：[AIS蛋白补充选择](https://www.ausport.gov.au/ais/nutrition/supplements/group_a/sports-foods2/isolated-protein-supplement2/how-and-when-do-i-use-it)、[AIS肌酸](https://www.ausport.gov.au/ais/nutrition/supplements/group_a/performance-supplements2/creatine)。用量与标签原则读[补剂模块](supplements.md)。

## 训练表现与出汗情境

| 成分 | 什么需求出现时再评估 | 本项目的选择边界 |
|---|---|---|
| 咖啡因 | 希望辅助某次训练表现，睡眠和耐受允许 | 合并咖啡、茶、能量饮料等总量，不用来顶替睡眠或掩盖长期疲劳；不把复合氮泵当必买 |
| 电解质粉 | 炎热、长时间运动或大量出汗，需要进一步考虑补液和电解质 | 先看时长、出汗和饮食；短时室内训练不自动配，标签中的钠与糖需核对 |
| 甜菜根、膳食硝酸盐 | 有特定耐力或运动表现任务，愿意按项目评估收益 | 先看硝酸盐实际含量、研究人群和任务；普通甜菜根粉不能按“一份”推断有效剂量，不承诺泵感等于增肌 |
| β-丙氨酸 | 有特定持续或反复高强度运动任务，且愿意持续补充 | 需按任务和持续周期评估，不是临时练前吃一次就生效；皮肤刺痒不代表效果更好 |
| 瓜氨酸或相关复配 | 用户明确想了解泵感、重复次数等表现，并愿意讨论有限证据与成本 | 证据不足以默认给所有健身者用。名称不清或混有精氨酸时先看标签，二者不能混称；不因血流机制就保证增肌效果 |
| EAA必需氨基酸 | 普通蛋白来源确有实际限制，或用户专门询问 | 先检查能否通过完整蛋白食物或蛋白粉解决；饮食已足时不优先单独买，不承诺练中服用即可阻断肌肉分解 |

来源：[NIH运动补剂事实表](https://ods.od.nih.gov/factsheets/ExerciseAndAthleticPerformance-HealthProfessional/)、[AIS成分框架](https://www.ausport.gov.au/ais/nutrition/supplements/group_a)、[AIS β-丙氨酸](https://www.ausport.gov.au/ais/nutrition/supplements/group_a/performance-supplements2/b-alanine)、[AIS蛋白成分说明](https://www.ausport.gov.au/ais/nutrition/supplements/group_a/sports-foods2/isolated-protein-supplement2/what-does-it-look-like)。专项剂量未在本页设为默认，实际选用前再核对成分资料。

## 饮食受限、微量营养与长期少吃鱼

| 成分 | 什么情况下再了解 | 选择边界 |
|---|---|---|
| 鱼油、藻油 | 长期少吃鱼且饮食难以调整，或已有具体专业用途 | 看EPA、DHA与用药，鱼油总重量不是有效成分量；不作为一般增肌减脂承诺 |
| 维生素D3、含K2的复配 | 日晒和饮食来源有限等风险值得关注，或已有明确补充要求 | 不能仅凭少晒太阳确诊；不要求所有健康人例行筛查。是否需要D和K分别判断，不因补D就自动配K2；使用华法林等药物时尤其需核对维生素K |
| B族维生素 | 长期饮食受限、有特定缺乏风险或专业要求 | 不把水溶性当无限量安全，不把参与能量代谢说成服用即提神；与复合维生素核对重复，尤其关注B6等实际含量 |
| 复合维生素 | 食物种类长期有限，单靠饮食暂难改善，或有具体专业需要 | 按饮食缺口选配方，不代替蔬果，不与多种单方机械叠加，不把主要外食直接当作需要购买的证据 |
| 维生素C | 饮食来源不足或有明确需要 | 不默认高剂量抗氧化促进训练适应，不因肌肉酸痛就补；先看水果蔬菜和其他产品中的重复量 |
| 果蔬粉 | 用户明确想解决蔬果难取得的实际困难 | 先考虑方便取得的完整蔬果；粉剂成分差异大，不能保证代替蔬果的纤维和食物多样性，不作为完整替换 |

来源：[NIH Omega-3](https://ods.od.nih.gov/factsheets/Omega3FattyAcids-HealthProfessional/)、[NIH维生素D](https://ods.od.nih.gov/factsheets/VitaminD-HealthProfessional/)、[NIH维生素K](https://ods.od.nih.gov/factsheets/VitaminK-HealthProfessional/)、[NIH复合维生素](https://ods.od.nih.gov/factsheets/MVMS-HealthProfessional/)、[NIH维生素B6](https://ods.od.nih.gov/factsheets/VitaminB6-HealthProfessional/)、[NIH维生素C](https://ods.od.nih.gov/factsheets/VitaminC-HealthProfessional/)、[FDA补剂与饮食说明](https://www.fda.gov/consumers/consumer-updates/fda-101-dietary-supplements)。其他矿物质如钙、铁按具体缺口另查，不预设健身组合。

## 睡眠、压力与恢复：先弄清困扰

用户实际问睡眠时，先进入[睡眠与恢复模块](sleep.md)。本节只在需要查具体成分时读取，不作为普通补剂回复的默认附表。

用户说睡不好，先了解入睡困难、夜间醒、作息偏晚、时差或白天嗜睡等实际问题，以及咖啡因、训练安排、近期睡眠与相关用药；不是见到睡眠差就同时上镁、ZMA、GABA、醉茄和褪黑素。持续或明显影响生活的睡眠问题需适当专业评估。

| 成分 | 何时进入讨论 | 证据与边界 |
|---|---|---|
| 甘氨酸镁或其他镁补充品 | 存在摄入不足风险、明确补镁需要，或用户专门询问睡眠用途 | 计量看元素镁，不是镁盐总重或固定几粒；睡眠效果证据有限，不能说甘氨酸镁必然改善深睡眠。肾功能与相关用药需核对 |
| ZMA锌镁复配 | 有对应营养需要且用户询问该复配 | 分开看锌、镁、B6含量和其他产品，不把“出汗多”直接当三者都缺，也不承诺提高睾酮或改善所有人的睡眠 |
| 褪黑素 | 倒时差或明确的昼夜节律相关问题值得评估 | 服用时机随问题决定，不给所有失眠者同一睡前方案；不替代慢性失眠的评估和治疗，不作为增肌恢复必需品 |
| 南非醉茄 | 用户有压力或睡眠困扰并明确想了解草本选择 | 部分研究提示潜在收益，不能凭压力大判断皮质醇高，也不保证阻止肌肉分解。制剂、肝脏与甲状腺风险、相关用药及适用人群需单独核对，不作第一步固定推荐 |
| GABA | 用户专门询问睡眠或压力用途 | 口服补充的睡眠获益证据很有限，不从神经递质机制直接推导有效；不默认加入睡眠组合 |

来源：[NIH镁](https://ods.od.nih.gov/factsheets/Magnesium-HealthProfessional/)、[NCCIH镁与睡眠](https://www.nccih.nih.gov/health/in-the-news-magnesium-supplements-for-sleep-disorders)、[NCCIH褪黑素](https://www.nccih.nih.gov/health/melatonin-what-you-need-to-know)、[NCCIH南非醉茄](https://www.nccih.nih.gov/health/ashwagandha)、[GABA系统综述](https://pubmed.ncbi.nlm.nih.gov/33041752/)。未把这些不同研究中的成分剂量拼成一套已验证的配方，也不声称本页完成了所有最新试验的系统评价。

## 有记录但不作为普通健身常规推荐

| 成分 | 当前处理 |
|---|---|
| 谷氨酰胺 | 普通健康训练者的表现与恢复获益证据不足以默认安排；特殊医疗或运动环境需另查相应研究，不宣称人人需要保护肠屏障或可阻止皮质醇分解 |
| 辅酶Q10 | 不因疲劳或健身就安排；有具体医疗用途或用户正在用时单独核对，不能把细胞供能机制等同一般运动表现收益 |
| 姜黄素 | 不把普通练后酸痛、关节不适或腱鞘问题直接当成需要补充；如用户询问，按具体问题评估有限证据和制剂差别，不宣称能治疗训练损伤，高生物利用度制剂有肝脏风险信息 |
| 绿茶提取物EGCG | 不作为普通减脂的默认选择，不设置“冲刺”加量；浓缩提取物与正常喝茶分开，高剂量及相互作用风险需要具体核对 |

来源：[NIH运动补剂](https://ods.od.nih.gov/factsheets/ExerciseAndAthleticPerformance-HealthProfessional/)、[NCCIH Q10](https://www.nccih.nih.gov/health/coenzyme-q10)、[NCCIH姜黄素](https://www.nccih.nih.gov/health/turmeric)、[NCCIH绿茶](https://www.nccih.nih.gov/health/green-tea)。这是对一般健身用途的取舍，不否定已确认的其他专业用途，不让用户擅自停换医疗方案。

## 实际输出和核对

先给个人三层结论，再展开与当前需求直接有关的少数成分。每个拟选项目说明“解决什么、为何适合、用多少、何时用、观察什么”；信息不足时先保留为情境备选，查标签后再定，不把库里的参考写成用户已经开始服用。

复配同时核对全部成分、单位与重复：维生素D/K、B族/复合维生素、单方镁/ZMA，以及咖啡、能量饮料与氮泵中的咖啡因等。不能将“1份”转换成任意产品1粒，不能把几种证据有限的成分叠加成更有效的组合。具体风险只在相关选择时解释，不把整份风险表输出给所有用户。
