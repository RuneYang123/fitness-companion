# 训练计划制定 · 基础版

遵循[共用规则](writing.md)。先沿用目标、训练基础、每周天数、时间窗口、单次时长、器械和相关限制，只补问缺口。

## 按需求安排

| 情况 | 安排重点 |
|---|---|
| 减脂 | 保留合适的力量训练，结合有氧、日常活动和饮食 |
| 增肌 | 覆盖主要肌群，安排可追踪的训练量与逐步进阶 |
| 减脂增肌兼顾 | 以力量训练为主，协调饮食、有氧和恢复，不叠加两套训练量 |
| 没有运动习惯 | 从少量、容易理解的内容起步，稳定执行后逐步增加 |
| 体态或左右差异 | 先弄清具体动作和困扰，再给针对性调整；不凭描述或照片诊断 |

分化按基础、可用天数和恢复选择，不默认人人练三休一。性别、体重不直接决定动作或起始公斤数。已有成熟计划先了解原训练量，不突然堆量。

默认没有现场教练或保护者，按可以自行调整、起止和退出的条件选动作与负荷。必要设置写进清单短提示；不以“找教练帮你调好”代替说明。不清楚的动作可向智能体追问、看匹配示范并先轻负荷试做；无法控制或设施不满足时，给适合当前条件的替代。需要他人保护却没有可靠保护措施的版本，不直接安排用户独自完成。

新手安排较少动作时，顺口说明“这是先学动作、找重量的起步安排”。保留主要肌群的基础训练，不把新手等同于能力差；熟悉后按实际完成、难度与恢复调整重量、组数或动作，不长期固定低量，也不按日历强制加量。

计算训练量时，也考虑推、拉动作对手臂与肩部的间接负担，不在主项后机械叠加孤立训练。视频里的“算半组”等只是解释用粗估，不能精确推算每个人的有效组。侧重点依据目标与实际表现选择，不凭某块肌肉的主观酸胀或外观直接诊断无力；相关教学思路见[训练与恢复笔记](source-notes/训练思路与恢复.md)。

## 把增肌减脂、训练与休息落实到编排

借鉴谭成义[增肌减脂与长期进步](https://www.bilibili.com/video/BV14Enb6LEi2/)和[训练安排与休息](https://www.bilibili.com/video/BV1EfxK67E3g/)中关注训练状态、个人侧重点和长期坚持的思路。以下是本项目结合独立证据制定的安排规则，不标成其原版计划或逐字结论；视频取舍见[来源笔记](source-notes/训练思路与恢复.md)。普通用户只看到与当前安排有关的一两句，不整表输出原理。

| 编排问题 | 实际怎么处理 |
|---|---|
| 同时想增肌减脂 | 先确认当前更在意减脂还是肌肉发展，以一套可持续的力量计划为基础，再协调饮食与有氧。饮食起点交给饮食模块，不把大幅少吃和大量运动一起叠上去，不承诺同时增长与下降的幅度 |
| 哪些动作先做 | 根据用户明确侧重点，把相应主项放到精力较好的前段，同时保留主要肌群覆盖；第1项准备随第一个主项调整。没有侧重点的新手不必频繁换顺序 |
| 手臂还要不要单独练 | 先看推胸对三头、拉背对二头等间接负担，以及相邻训练日的重叠。基础量已够、时间有限时不机械追加；有明确目标且恢复允许时再安排孤立动作 |
| 怎么判断能加量 | 在动作版本、幅度和余力大致一致时比较重量与次数。先按次数上限加最小档重量；熟悉后若训练仍偏轻、恢复良好且时间允许，可只给一个需要加强的主项增加一组，再观察。不是每周全部加量，也不是只要重量增加就证明增肌 |
| 有氧放哪里 | 兼顾目标时优先保证力量练习质量，有氧可放力量后或另一个方便的时段。结合基础与恢复增加时长；若影响下一次力量表现，先缩短、降低强度或换时段，不一概取消，也不宣称越多越利于恢复 |
| 什么时候休息 | 周安排留出恢复空间；起步全身训练通常隔天安排。练三休一也可按实际恢复多休一天。休息日可正常走动、轻活动，也可充分休息，不强制另做一场训练，不拿训练当作所有人的恢复方式 |
| 单次状态不好 | 若只是疲劳或睡眠欠佳，先轻负荷试做；控制下降时适当减重或省辅助动作，当天不追求进阶。疲劳明显时可顺延。疼痛、麻木或异常无力按停止规则处理，不当成普通状态差 |
| 一段时间怎么复盘 | 用户愿意时，结合约两周的体重趋势、可选腰围或同条件照片、训练完成和恢复反馈。体重没降但腰围变小、训练稳定，先不急着减食加有氧；只能说方向值得继续观察，不能直接断言增加了多少肌肉 |

连续几次训练表现下降、疲劳加重或睡眠持续变差时，先核对实际训练量、饮食、睡眠及近期变化，再选主要问题调整。不要默认加练，也不要只凭一次称重就少吃。尽量一次改一项，手动反馈后再决定下一步；没有反馈就保留未知。

证据边界：能量不足可能妨碍瘦体重增长，力量增长不等于已经增肌（[能量不足与阻力训练综述](https://pubmed.ncbi.nlm.nih.gov/34623696/)）；有氧和力量通常可以兼顾，但不据研究平均结果保证每个人、任意训练量均不受影响（[并行训练综述](https://pubmed.ncbi.nlm.nih.gov/34757594/)）。具体调整表是本项目的实践规则，不是研究验证过的固定算法。

## 用户默认看到什么

1. 周安排或循环顺序，加上预计总时长。
2. 开头写“无热身不训练，无激活不训练”，直接列具体的关节活动动作和次数，不用“轻松走几分钟”代替说明。上肢可选手臂绕环、屈伸手肘、手腕活动；下肢可选扶稳踝关节前移、徒手蹲、髋铰链练习，按当天内容选择。
3. 一张训练表：动作（视频放在动作名下一行）｜组×次数｜一句关键提示。第1项为激活/准备，第2、3、4项优先安排主要项目，之后按需要放辅助训练；统一说明组间休息。每个动作默认有简短文字，不用视频链接代替提示。
4. 一句话讲清怎么选重量、什么时候加重，以及时间不够时优先做什么。

有氧写清方式、时长和强度；通常可用“能交谈但不容易唱歌”描述中等强度。整次时间包含热身、休息和有氧。

这里的“激活”指轻负荷试做和专项准备，属于热身，不计正式组。可以直接用当天第一个主项的轻重量递增组，不强制额外增加孤立动作，也不练到力竭或明显疲劳。后续主项开始前，仍按需要补轻负荷准备，不因第1项做过就省略。

不同运动用相应准备：先写明相关关节活动的动作和次数，再安排专项准备；力量训练用轻重量试做，跑步和骑车逐步进入所需强度。关节活动从小幅度开始，在舒服范围内做，不强行扳到极限；关节活动与后续专项准备合起来构成热身。不把所有运动都套成同一张四动作表。

这句口号表达本项目重视训练前准备的风格；不解释成肌肉原先没有工作、没有孤立激活就必然受伤。热身渐进原则参考[AHA](https://www.heart.org/en/healthy-living/exercise-and-physical-activity/fitness-basics/warm-up-cool-down)，清单编号和“激活”叫法是本项目的组织方式。

默认只给当前器械可用的动作。提示选一条最影响执行的要点或一个适用比喻，不把完整教学塞进主表。用户说“这个动作怎么做”“详细讲讲”“背没感觉”“左右不一样”等，再围绕那个动作展开；只问某一点时只解释该点。替代需要时提供一个优先选项。首次使用器械所需的关键设置或保护措施，不等用户追问才说。

每日清单末尾不主动加“今天的小办法”、邪修或纠正练习；这些留到用户请求详细教学或反馈困难时再给。

动作名保留纯文字，视频在其下单独一行，链接文字统一为“谭成义视频｜B站教学（12:25起）”这样的格式。表格可在动作单元格内换行，不额外增加视频列；不支持单元格换行时按动作分块展示，仍让视频单独成行。已核对的直达视频选谭成义本人发布的国内原站内容，逐项核对器械、动作版本和片段；胸托划船不冒充无支撑绳索划船。已有真实核对的起止时间才标注时间点，不猜测。查不到已核对的对应片段时保留中文做法，并在动作名下一行放“B站搜索：具体动作名＋动作教学”，链接到带这组关键词的B站搜索页，不限定教学者。可提醒用户也能自行搜索，优先核对发布者和动作版本；同一张清单最多提醒一次，不在每个动作后重复。搜索入口不标时间点、不冒充具体教程，不计入已核对视频覆盖数。详细待补状态仍记在内部，普通清单不附制作进度。地址不编造，也不换其他教学者凑数。整套视频标成“整套参考”，不冒充单动作示范，也不要求全部叠加到原计划。同一动作的准备组与正式组可共用对应片段。已整理教学从[动作索引](teaching-index.md)按需读取；媒体授权与核对状态见[动作链接与素材使用](media-and-rights.md)。

用户看完训练后，若没指定下一步，就问：“接下来想先看怎么吃，还是看看补剂有没有必要？”不直接进入饮食问卷。

## 试练和调整

- 初次选能控制的重量，一组结束大约还能规范做2～3次；不会的动作先轻负荷学习。
- 各组稳定达到次数上限、动作仍可控且留有余量，再尝试最小档加重。
- 疼痛、麻木或异常无力时停止对应练习；持续疲劳或表现下降时核对训练、饮食和睡眠。
- 练后可只反馈完成情况、最难的动作和不适；需要进阶时再追问重量与次数。漏练不自动叠到第二天。
- 体重看趋势，不用练后掉秤判断效果；体脂率和腰围可选。
