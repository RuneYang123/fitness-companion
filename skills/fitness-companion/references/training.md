# 训练计划制定 · 基础版

遵循[共用规则](writing.md)。先沿用已知的目标、训练基础、每周可练天数、单次时长、场地器械和伤病限制，只补问缺口。

## 1. 按需求与个人条件编排

| 情况 | 安排重点 |
|---|---|
| 减脂 | 保留维持肌肉所需的力量训练，协调饮食、有氧和日常活动 |
| 增肌 | 覆盖主要肌群，安排可追踪的训练量与渐进超负荷 |
| 减脂增肌兼顾 | 以一套可持续的力量计划为主，协调饮食与有氧，不叠加两套训练量 |
| 没有运动习惯 | 从少量、好上手的基础动作起步，能稳定执行后再加量 |
| 体态或左右差异 | 先问清具体动作和困扰，再给针对性调整；不凭描述或照片下医疗诊断 |

- **分化与起步量**：按基础、可用天数和恢复选分化（如每周 3 天新手优先[全身A/B轮换](example-gym-beginner.md)，不硬套练三休一）。新手动作少时顺口说明“这是先熟悉动作、找准重量的起步安排”，熟悉后再按恢复加量。
- **独自训练安全第一**：默认无现场教练或保护者。选择用户能自己安全调节、起落和退出的动作与重量；关键器械设置（座椅高度、安全卡扣、限位销）直接写进提示，不用“找教练帮你调”代替说明。
- **兼顾间接负担**：计算容量时把推胸对三头、拉背对二头及肩部的间接负担算进去，不在主项后机械堆砌孤立动作。

## 2. 增肌减脂、排序与恢复决策表

借鉴谭成义[增肌减脂与长期进步](https://www.bilibili.com/video/BV14Enb6LEi2/)和[训练安排与休息](https://www.bilibili.com/video/BV1EfxK67E3g/)中关注训练状态、个人侧重点和长期坚持的思路，结合独立循证原则（[能量不足与阻力训练综述](https://pubmed.ncbi.nlm.nih.gov/34623696/)、[并行训练综述](https://pubmed.ncbi.nlm.nih.gov/34757594/)）执行：

| 编排问题 | 实际处理方式 |
|---|---|
| 同时想增肌减脂 | 先确认当前更优先哪一头，用一套力量计划打底，不把“大幅砍热量”和“大量加训练”同时叠上去 |
| 哪些动作先做 | 把用户最想改善或最需要精力的复合主项放在前段（第 1 项激活准备随第一个主项调整）；无特殊侧重的新手保持固定顺序即可 |
| 手臂要不要单练 | 基础推拉量已够、时间紧时不额外追加；有明确手臂目标且恢复良好时再加 1～2 个孤立动作 |
| 怎么判断能加重 | 动作幅度和控制一致时，全部正式组稳定做到次数上限且仍有 2～3 次余力，下次加最小一档重量；或只给一个主项加 1 组观察反应 |
| 有氧怎么放 | 优先保住力量训练质量，有氧放力量后或分开时段；若影响下次力量表现（尤其腿日），先缩短、降强度或换时段 |
| 休息日怎么排 | 起步全身训练建议隔天练；练三休一也可按恢复多休一天。休息日可散步或充分休息，不强制补练 |
| 单次状态不好 | 睡眠欠佳或疲劳时先轻重量试做准备组；控制下降就减重或省掉末尾辅助/有氧，明显吃力就顺延，不把漏练挤到一起 |
| 连续几次状态下滑 | 先排查训练量、饮食和睡眠，一次只改最主要的一项；不凭单日体重波动就砍饭加练 |

## 3. 用户默认看到什么

1. **周安排或循环顺序**，加上包含热身、休息和有氧的预计总时长。
2. **标志性热身口号与具体关节活动**：开头写 **“无热身不训练，无激活不训练。”** 直接列出当天要用到的关节活动动作与次数（如上肢：手臂前后绕环、屈伸手肘、手腕绕环各 8 次；下肢：扶稳踝关节前移、徒手深蹲、徒手髋铰链各 8 次），不用“轻松活动几分钟”敷衍。热身渐进原则参考 [AHA](https://www.heart.org/en/healthy-living/exercise-and-physical-activity/fitness-basics/warm-up-cool-down)。
3. **训练主表**：
   - **第 1 项为激活/专项准备**（可用当天第一个主项的轻重量递增试做，属于热身，不计正式组，不练到力竭）；
   - **第 2、3、4 项优先排主要复合动作**，后续放辅助动作；后续主项开练前仍按需补 1 组轻重量试做。
   - **视频/搜索入口另起一行**：从[动作教学索引](teaching-index.md)匹配对应版本。已核对直达视频写 `[谭成义视频｜B站教学（12:25起）]`；无匹配直达片段写 `[B站搜索｜具体动作名动作教学]`。
4. **重量、休息与应变一句话**：说明正式组选“做完还能规范做 2～3 次”的重量、组间休息时间，以及时间不够时先省哪项。有氧写清方式、时长和“能交谈但不容易唱歌”的中等强度参照。

## 4. 下一步衔接与示例参考

- 用户看完训练后，若未指定下一步，自然询问：“接下来想先看怎么吃，还是看看补剂有没有必要？”
- 出现疼痛、麻木或异常无力时立即停止对应动作。单动作详解见[动作问答](exercise-help.md)，器械受限见[动作替换](substitutions.md)。
- 编排形式参考：[新手每周三练A/B](example-gym-beginner.md)、[健身房增肌PPL](example-gym-ppl.md)、[减脂PPL](example-fat-loss-ppl.md)、[居家兼顾](example-home-recomposition.md)。阻力训练与活动量原则参考 [ACSM](https://acsm.org/resistance-training-guidelines-update-2026/) 与 [CDC 成人活动建议](https://www.cdc.gov/physical-activity-basics/guidelines/adults.html)。
