# 补剂评估设计 · 基础版

遵循[共用规则](writing.md)。先判断实际需要，允许结论为“目前不用补”。减脂不默认配补剂。

训练之后可由用户选择先看饮食还是补剂，不省略补剂入口，也不自动生成服用清单。具体选用时沿用已有补剂、饮食、目标、标签及相关限制，缺信息再问“现在手上有没有在吃的补剂，或者特别想了解哪一种？”。用户在讨论模块设计、正常推荐或备选清单时，可先展示条件化选项，不要求先完成问卷；未知适用性不写成已确认。

## 必须、可选、特定情况再考虑

- “必须补”不能预置固定产品。普通成人健身可能没有必补项，清楚写“目前没有明确必补项”。营养需要必须满足，不等于必须用补剂满足。已确诊缺乏或有明确医疗补充要求时单列，按具体专业方案处理，不从疲劳、抽筋或很少晒太阳直接确诊。
- “可选”指当前目标和条件下已经值得讨论、但用户可自主决定的项目。例如饮食确有缺口时的蛋白粉、适合规律力量训练者的单水肌酸。写清选它的理由，不把“能吃”当成“有必要”。
- “特定情况再考虑”指当前不安排使用，只有出现具体需求、风险线索或运动任务时才进一步评估，如大量出汗、长期很少吃鱼、日晒有限、倒时差、持续睡眠问题或专项表现目标。写“什么情况下再看哪项”，不是看到症状就开一串补剂。
- 三层按人和当前信息划分，不是给产品永久贴标签。同一维生素在尚无需要时可以不列，存在风险时进入评估，已有明确医疗补充要求时才可能成为必须处理的项目；蛋白缺口必须解决也不等于必须买蛋白粉。
- 用户只看自己的方案时，列“必须：目前有或没有明确项目”，再给最相关的可选项和一两条情境备选；用户要求完整备选或询问某成分时，再读取[补剂扩展候选与需求判断](supplement-options.md)。候选资料可以广，日常服用表保持短，不将所有备选都加入安排。
- 给当前优先顺序：如先检查是否真有蛋白缺口，再让有力量目标且适合的用户自行决定是否用肌酸；鱼油、维生素等按饮食和具体风险进入。用户已确定使用的项目与尚未选择的备选分开。

## 怎么判断

睡眠和恢复有[独立模块](sleep.md)。普通补剂回复不默认展开睡眠补剂表；用户提到睡眠问题时转入该模块，先了解问题和日常安排，确有相关需要再回到成分选择与标签核对。

| 可选项目 | 选它的角度：什么时候考虑 | 选择前确认与使用原则 |
|---|---|---|
| 蛋白粉 | 三餐实际蛋白没吃够，或外食、出差时用粉更方便 | 按饮食缺口补；核对配料、过敏和标签，吃够了不再机械追加，不强制练后立即喝 |
| 单水肌酸 | 希望辅助规律的力量或短时高强度训练，且愿意持续使用 | 确认适用性与产品成分；健康成人常用每日3～5g，可不做冲击期，休息日也用。不是直接燃脂，开始后可能因水分增重 |
| 维生素D | 日晒很少、饮食来源不足等使摄入或状态值得关注，或已有明确补充要求 | 少晒太阳只是风险线索，不等于确诊缺乏。结合饮食、风险和已有结果判断，不要求所有健康人先做筛查，也不直接给缺乏治疗的大剂量 |
| 鱼油或藻油 | 长期很少吃鱼，且饮食难以调整时，讨论补充长链Omega-3的需要 | 先看食物来源和实际目标；看EPA、DHA含量及相关用药，不只看鱼油总重量，不承诺因此增肌或减脂 |
| 咖啡因 | 想辅助某次训练表现，日常摄入、耐受和睡眠允许时 | 不是用来硬顶长期疲劳；临近睡眠、容易心慌或已有不耐受时不优先选。核对咖啡、茶、能量饮料等总摄入，不默认需要氮泵 |
| 电解质 | 炎热环境、较长时间运动、大量出汗等需要补充水和电解质时 | 普通室内训练先考虑水和正常饮食，按实际时长、出汗与产品钠含量评估；含糖产品也计入摄入，不因开始健身就每天喝 |

运动相关项目见[NIH运动补剂](https://ods.od.nih.gov/factsheets/ExerciseAndAthleticPerformance-HealthProfessional/)与[AIS框架](https://www.ausport.gov.au/ais/nutrition/supplements/group_a)，肌酸用法见[AIS成分资料](https://www.ausport.gov.au/ais/nutrition/supplements/group_a/performance-supplements2/creatine)。维生素D和Omega-3分别核对[NIH维生素D](https://ods.od.nih.gov/factsheets/VitaminD-HealthProfessional/)与[NIH Omega-3](https://ods.od.nih.gov/factsheets/Omega3FattyAcids-HealthProfessional/)。本表是选择参考，不是六样一起吃的方案。

钙、铁、镁及复合维生素等在用户有相关饮食限制、缺乏风险或具体问题时再评估；不因为用户健身或主要吃外卖就自动加入，也不凭症状安排治疗剂量。已存在的医疗补充方案不能随意停换。

其他产品按用户问题查证，不默认推荐燃脂产品或整套恢复补剂。成分有效不等于人人需要；已有疾病治疗不自行停换。

## 默认输出

先给三层结果：“必须：有或没有明确项目；可选：当前值得讨论的项目和理由；特定情况：出现什么需求再考虑什么”。空层可写暂无，不为填满表格凑项目。用户只要简版时，可选保留最相关的一两项，情境备选也只写相关例子；用户要求完整备选时再按需求展开，不机械附所有未采用的产品。确定选用后才给实际用量、怎么用和需要留意的一点；资料不足时可以给有适用条件的一般参考，不伪装成个人处方。

用量依赖产品标签与相关限制；没有标签不猜几勺几粒。30g粉不等于30g蛋白，鱼油总重不等于EPA+DHA，镁盐总重不等于元素镁。

蛋白粉按缺口算；计算过程留在内部，用户想看再解释。健康成人单水肌酸常见每日3～5g只是需核对适用条件的参考，不是默认处方。

样例见[12](example-supplements.md)。详细研究见[证据索引](supplement-evidence.md)：按目标、人群和结局核对，不用品牌宣传或单个机制代替效果证据。具体建议保留简短可靠来源。

用户可随时反馈实际用了什么、多少，以及有没有不舒服；不要求每日汇报，也不把“可以考虑”写成已经采用的安排。
