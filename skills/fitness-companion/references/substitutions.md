# 身体重组与动作替换 · 按需参考

遵循[共用规则](writing.md)。减脂增肌兼顾采用一套协调的力量、活动和饮食安排，不保证固定时间内同时达到指定结果。

先读[训练编排中的增肌减脂与恢复规则](training.md)，再按实际场地替换。保留主项质量和可追踪的进步，不因居家器械轻就无限增加次数、组数和有氧。体重变化、训练表现与恢复一起看；重量上升不单独当作增肌证据。休息日活动可选，恢复不足时可顺延。

居家先确认实际器械、负荷范围、空间与可靠支撑。没有器械时说明训练缺口，不硬凑等效动作。

| 原项目 | 可考虑的替代 | 关键差别 |
|---|---|---|
| 器械推胸 | 哑铃地板卧推、合适高度的俯卧撑 | 范围、难度和负荷不同 |
| 坐姿划船 | 单臂哑铃划船、可靠固定的弹力带划船 | 需重新确定支撑和负荷 |
| 高位下拉 | 有可靠高位固定点的弹力带下拉 | 无设施时承认缺项，水平拉不完全等效 |
| 史密斯深蹲 | 高脚杯深蹲、适合的徒手蹲 | 负荷与稳定要求不同 |
| 罗马尼亚硬拉 | 合适的负重髋铰链版本 | 徒手学动作、臀桥只能部分覆盖 |
| 跑步机有氧 | 户外快走或室内低冲击活动 | 按实际强度和时长重新安排 |

只展示当前需要的一个替代。先轻负荷试练，重新选组次和难度，替换原项目而非追加；公斤数不能直接沿用。不用门缝床单、不稳桌子做悬挂。

时间不足时优先保留主要动作和必要热身、休息。经常超时或长期缺器械时重新排计划；疼痛单独处理，不当成普通器械替换问题。

按用户提供的内容记录实际动作、组次、负荷；临时替代不自动改永久计划，长期修改后下次使用新安排。

依据：[ACSM居家阻力训练原则](https://acsm.org/resistance-training-guidelines-update-2026/)、[能量不足与阻力训练综述](https://pubmed.ncbi.nlm.nih.gov/34623696/)。替代关系为本项目候选，不是数据集自带处方。
