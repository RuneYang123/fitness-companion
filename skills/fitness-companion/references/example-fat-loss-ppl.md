# 练三休一 · 健身房减脂示例

编写备注（不输出给训练用户）：本页演示编排形式，动作和训练量仍按当前用户条件调整。实际回复须从[教学索引](teaching-index.md)选匹配视频并另起一行；未匹配的给明确标注的通用B站搜索入口，不直接照搬缺少视频入口的示例表。

虚构展示：已能规律训练、熟悉动作且无相关限制的成年人，每次约60～75分钟。具体需按个人调整，遵循[共用规则](writing.md)。

按“推→拉→腿→休息”往下练。力量照常练，再配一点有氧，吃饭也一起调整。

**无热身不训练，无激活不训练。** 先按当天内容活动关节，下面写了具体动作和次数；从小幅度开始，舒服地做，不硬扳。

| 当天 | 具体准备 |
|---|---|
| 推 | 手臂前后绕环各8次、屈伸手肘8次、手腕轻柔绕环每方向8次，墙壁俯卧撑8次 |
| 拉 | 双臂前伸收回8次、屈伸手肘8次、手腕轻柔绕环每方向8次 |
| 腿 | 扶稳踝关节前移每侧8次、徒手深蹲8次、徒手髋铰链8次 |

表内第1项是激活准备，不计正式组，也不练累。划船开始前轻重量8次，上斜卧推、硬拉开始前各补一组轻重量5～8次，按工作重量适当增加准备。

**训练清单：** 推胸、卧推、下拉、划船、深蹲和硬拉，组间休息2～3分钟，其他动作60～90秒。这组做完，动作不变形还能再做2～3次，重量就差不多。

| 推日 | 组×次数 | 提示 |
|---|---|---|
| 1. 激活：轻重量推胸 | 很轻8～10次，稍加重量5次 | 先把轨迹做顺，不练累 |
| 2. 器械坐姿推胸 | 3×8～12 | 脚踩稳、背有支撑，平稳推回 |
| 3. 上斜哑铃卧推 | 2×8～12 | 左右同步，不扭身体 |
| 4. 哑铃侧平举 | 2×12～20 | 不甩身体 |
| 5. 绳索三头下压 | 1×10～15 | 大臂相对稳定 |

| 拉日 | 组×次数 | 提示 |
|---|---|---|
| 1. 激活：轻重量下拉 | 很轻8～10次，稍加重量5次 | 先试握法和轨迹，不甩身体 |
| 2. 高位下拉 | 3×8～12 | 不靠大幅后仰甩重量 |
| 3. 胸托坐姿收肘划船 | 3×8～12 | 手肘向后，身体不前后摆 |
| 4. 反向蝴蝶机 | 1×12～20 | 轻重量平稳打开 |
| 5. 哑铃弯举 | 1×10～15 | 不挺腰甩动 |

| 腿日 | 组×次数 | 提示 |
|---|---|---|
| 1. 激活：轻负荷史密斯深蹲 | 最低合适负荷8次，稍加重量5次 | 安全挡位调好，空杆也要确认能控制 |
| 2. 熟悉的史密斯深蹲 | 3×8～12 | 全脚掌踩稳，控制下蹲范围 |
| 3. 哑铃罗马尼亚硬拉 | 2×8～12 | 屁股向后，哑铃靠近身体 |
| 4. 器械腿弯举 | 2×10～15 | 调好垫位，控制还原 |
| 5. 有支撑的双脚提踵 | 1×12～20 | 平稳抬放，不弹跳 |
| 6. 死虫式 | 2×每侧6～10 | 躯干稳住，持续呼吸 |

推日力量后快走或单车25分钟；拉日单车或椭圆机25分钟；腿日平地走或低阻力单车15分钟。每次选一种，强度参考“能交谈但不容易唱歌”，结束慢下来约3分钟。腿部明显疲劳时缩短或省略。

休息日不补量，恢复不足可顺延。有疼痛、麻木或异常无力时停止对应练习；时间经常不够就重新排，不赶动作。

每组都能稳稳做到表里的次数上限、还留点力气，下次再加最小一档重量。练完直接说：“今天拉日练完了，有氧做了20分钟，没有不舒服。”
