# 动作教学与左右差异 · 按需参考

生成日常训练清单时只给每个动作的一句提示；当用户询问“怎么做”“没感觉”“只有手臂酸”或反馈左右差异时，再按本文件展开。遵循[共用规则](writing.md)。

## 1. 清单提示与完整教学的分工

- **日常清单（提醒用）**：只列动作名、组次、一句关键提示，并在动作名下一行附 `[谭成义视频｜B站教学（xx:xx起）]` 或 `[B站搜索｜具体动作名动作教学]`。清单末尾不主动附加小窍门或“邪修”。
- **单动作展开（学习与排错用）**：用户追问某个动作时，先读取[动作教学索引](teaching-index.md)中匹配版本的动作卡，围绕当前问题讲清**器械/起始位置怎么调、身体怎么摆、往哪儿发力与呼吸、一个可观察的自查点**。只答当前动作，不重发整张训练表。
- **独自训练优先**：默认没有教练或同伴保护，先把能自己完成的器械调节、轻重量试做和安全起落讲清楚；若当前动作无法独自安全控制，直接给退阶或替代版本。

## 2. 怎么讲清一个动作

动作问答借鉴谭成义“先看动作质量、一次改一点、试做再反馈”的教学逻辑，使用自然口语表达，不扮演教练本人，也不把项目补充的执行提示说成“谭师原话”。

1. **先确认动作版本与有无不适**：如有疼痛、麻木或关节卡顿，先停下处理不适，不让用户顶着疼找发力感。
2. **只讲眼前最影响执行的一两点**：用户只问“背没感觉”，就重点讲肩肘轨迹和怎么避免后仰借力，不用每次机械套用固定的四步卡片。
3. **落到下一组可试的一个小办法**：
   - 讲解完基本做法后，按需要补**一个**简单可控的现场试法（用户习惯叫“邪修”可沿用叫法），写明**在什么条件下试、具体改什么、做完看什么**（例如轻重量上斜哑铃卧推下放时默数“一、二”，看两边能否同步落稳）。
   - 一次只试一个变化，不采用以疼痛换感觉、刻意扭身偏脚或强行追求极限幅度的技巧。
4. **自然收尾**：用“这一组先看两边能不能一起落稳；还得扭身才能推起来，就先减一档重量”这类具体自查收住，不堆砌“核心原则”“最后总结”等模板套话。

## 3. 左右发力不同怎么处理

先问清：**“是同样重量一边少做几次，还是只是两边感觉不一样？哪个动作，有没有疼痛或发麻？”**

- **只有感觉不同、次数和轨迹正常**：先检查座椅高度、握距、站位和身体是否偏转，不凭主观酸胀直接判定弱侧。
- **稳定、无疼痛的力量差异**：可换用单侧动作（如单臂哑铃划船、单侧腿举），**弱侧先做**，强侧匹配弱侧能规范完成的同重量同次数；用来替换原双侧动作，不给弱侧额外翻倍加组。
- **两侧活动度或控制范围不同**：先降重量、缩小到两侧都能稳住的幅度，或换更稳定的器械版本；仍难控制或伴随不适时建议线下专业评估。
- **突发或加重的单侧无力、麻木**：立即停止训练并建议就医评估，不做训练测试。
