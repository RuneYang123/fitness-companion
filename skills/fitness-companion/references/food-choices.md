# 日常食物与外卖怎么选

饮食模块的按需参考，用户问“哪些能吃、哪些少吃、具体点什么”时读取。通用食物选择，不写入个人资料。核对日期：2026-11-05。

## 怎么介绍

按“日常优先、偶尔换口味、尽量少选”给具体食物与点法。这是项目为了方便选择做的整理，不是指南对每道菜的官方分级，也没有统一的每周允许次数。常选仍需合适份量；同一道菜随原料、烹饪和搭配可改变选择优先级。

不把普通食物列成永久禁食表，不使用“垃圾食物”“吃坏了”“必须用运动赎回来”等说法。用户说“放纵餐”时可自然改成“想吃的那一餐”；不安排无限量吃的放纵日，不要求前后挨饿、砍主食或加练补偿。避免把没有过敏或相关疾病限制的普通食物说成一口都不能吃。

## 日常优先：组成大多数正餐

| 类别 | 具体可以选什么 | 怎么吃更实用 |
|---|---|---|
| 主食 | 米饭、杂粮饭、原味燕麦、馒头、普通面条、玉米、蒸红薯、全麦面包 | 白米饭、白面也能正常吃，轮换一部分全谷物；玉米、红薯算主食，不是额外加的蔬菜 |
| 蛋白来源 | 清蒸鱼、清煮虾、去皮鸡腿、鸡胸、水煮蛋、豆腐、豆干、无糖豆浆；瘦猪肉和瘦牛肉也可轮换 | 鱼、禽、蛋、豆类交替，不长期只靠一种肉；豆制品、豆浆和肉的份量不能直接等重互换 |
| 蔬菜 | 小青菜、菠菜、西兰花、番茄、黄瓜、冬瓜、胡萝卜、菌菇 | 清炒、清蒸、白灼或少油做法；茄子、土豆等食材本身与油炸、干锅做法分开判断 |
| 奶类 | 纯牛奶、无添加糖酸奶 | 全脂奶也可以安排，需控制脂肪或热量时选低脂；酸奶不只看包装上的“高蛋白”“轻食”字样 |
| 水果 | 苹果、橙子、猕猴桃、香蕉、梨、当季水果 | 吃完整水果，按原计划份量；香蕉不用因减脂被禁掉，果汁不等于完整水果 |
| 脂肪来源 | 原味坚果、日常适量植物油 | 坚果按小份吃，油计入全天脂肪；“健康”不代表能无限加量 |

依据：中国营养学会[食物多样与合理搭配](https://www.cnsoc.org/bookpublica/0522202019.html)、[适量吃鱼禽蛋瘦肉](https://dg.cnsoc.org/article/04/3tyM8WoTTUmc_oFHMymk3Q.html)和[蔬果奶类全谷大豆](https://dg.cnsoc.org/article/04/70JvPbFmTlyZbjoO67LeRg.html)。菜品例子和选择顺序由项目结合指南原则整理，非逐道菜的临床比较。

## 偶尔换口味：能吃，留意做法和搭配

| 具体例子 | 怎么安排 |
|---|---|
| 红烧肉、回锅肉、糖醋里脊、油重的干锅 | 选小份，配正常主食和蔬菜；不把一份肥肉多的菜等同于计划里的同重瘦肉 |
| 炒饭、炒面、拌面等油量可能较多的主食 | 作为这餐的主食，补合适的蛋白来源和蔬菜，不再机械叠一份米饭 |
| 披萨、酱多或炸肉的汉堡 | 想吃时选合适份量，搭配水和蔬菜；薯条、甜饮、甜点不必整套叠加 |

“偶尔”是选餐建议，不是这些名称天然不健康。牛肉面、包子、饺子、黄焖鸡、麻辣烫等先看实际肉量、蔬菜、油盐和总份量，能调整得合适时也可成为日常正餐，不按菜名直接判成放纵餐。

## 尽量少选：解馋时小份，不作日常基础

| 类别 | 具体例子 | 提醒 |
|---|---|---|
| 含糖饮料 | 加糖奶茶、普通汽水、甜果茶、含糖乳饮料 | 日常优先水、无糖茶等；想喝时选小杯、减少加糖和配料，不承诺低糖就一定低热量 |
| 油炸和高糖零食 | 炸鸡、薯条、油条、薯片、奶油蛋糕、甜甜圈、糖果 | 选择自己想吃的一样和合适份量，不设必须完成的放纵日；吃过后下一餐照常 |
| 高盐加工肉 | 香肠、培根、午餐肉、腊肉、部分火腿肠 | 少拿这些当日常主要蛋白来源，不能因为蛋白质含量高就忽略盐和脂肪 |
| 酒 | 啤酒、白酒、葡萄酒及含酒精饮料 | 不为营养或健身推荐饮酒，也不把它设成放纵餐奖励；能不喝就不喝 |

少油炸、少高盐、少含糖饮料的依据见[中国营养学会](https://dg.cnsoc.org/article/04/ApX3_ozGTmSoqQaFFh5z_Q.html)与[WHO健康饮食](https://www.who.int/en/news-room/fact-sheets/detail/healthy-diet)。饮酒不存在零风险的方式，见[WHO酒精说明](https://www.who.int/news-room/fact-sheets/detail/alcohol)。不从这些总体建议推导“一次吃了就会损害减脂效果”或虚构具体食品的疾病风险百分比。

真正应避免食用的是已经霉变、腐败或储存不安全的食物，不因为聚餐或所谓放纵而例外；参考[WHO食品安全五要点](https://www.who.int/docs/librariesprovider2/default-document-library/5keys_en.pdf)。普通清单只在用户问到“完全不能吃”或涉及具体食品安全时简短说明，不额外附整套卫生检查表。

## 外卖可以这样点

| 店型 | 店里有相应菜品时可这样搭配 | 留意什么 |
|---|---|---|
| 小碗菜、自选快餐 | 米饭＋清蒸鱼或鸡肉、豆腐类菜＋两样蔬菜 | 菜名带“蔬菜”也可能油多；看实际肉量，酱汁不拌饭 |
| 沙县小吃 | 有鸡腿饭时选鸡腿饭，加青菜；去皮去骨后看肉量是否够 | 不把汤里的几块肉当作一份足量肉，也不承诺各门店都有同款菜单 |
| 麻辣烫 | 蔬菜＋豆腐或鸡蛋、鲜肉片＋适量粉或面，清汤、少油少盐 | 少堆加工丸类、油条和麻酱，汤不作为必须喝完的部分 |
| 黄焖鸡 | 鸡肉＋米饭，能加青菜就加，少拌汁 | 肉多皮少，实际油量和份量仍看门店 |
| 轻食店 | 有明确肉量的鸡肉或鱼肉饭，蔬菜足，酱单独装 | 保留适量米饭或薯类，不只吃一盒菜；“轻食”标签不保证低热量 |
| 便利店、早餐店 | 原味燕麦或合适主食＋纯奶或无糖豆浆＋鸡蛋，按需要配水果 | 奶饮料与纯奶、甜麦片与原味燕麦分开；份量接原饮食计划 |

这是常见组合候选，不代表已核对某家门店当前菜单、库存、价格或热量。用户要具体品牌产品或现售套餐时再查当前资料；有城市、预算或菜单时沿用，不要求住址。

## 输出控制

默认顺序是“简短饮食建议→具体食物清单→可选的一日组合或外卖点法→拍照反馈入口”。不强制克重，份量先用饭碗、手掌、拳头或包装单位帮助理解。所有份量都是粗略参照，不等同精确热量或营养目标；用户需要精细记录再给克重，方法和照片判断边界见[饮食模块](nutrition.md)。不把拍照设成必做任务。

用户只问能不能吃某一样时，只回答那一样和当餐怎么安排。用户要完整食物清单时才展示分类；与原食谱衔接时按计划份量替换，不把列表中的所有食物都追加。首次只给最相关的食物和两三种店型，更多列表留待追问。

蔬果、鱼禽豆奶等建议按[饮食模块](nutrition.md)结合个人目标与限制采用，不把这一份通用清单当作所有人的热量和蛋白处方。
