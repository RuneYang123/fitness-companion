- 0:22～1:15：主要从健美展背与肩胛运动讨论背部表现，不是某个划船动作的完整设置教程，不能直接贴到当日动作上。
- 1:17～4:36：用胚胎、额叶、小脑等解释体态与疼痛。这部分没有随片提供可核对证据，不进入本skill的因果解释或诊断逻辑；不从体态推断大脑发育或功能。
- 4:37～5:48：谈训练质量、前一天饮食睡眠与当天状态。可适配为“动作先能控制，再考虑加重；状态差时调整当天任务”，不据此取消训练记录、计划或所有组次，也不说不完美的训练毫无效果。

## 呼吸与恢复

原片：[BV1czHuzPExA](https://www.bilibili.com/video/BV1czHuzPExA/)，7:30。

- 0:21～1:56：谈饮食、睡眠与轻活动。保留对恢复状态的关注；具体营养仍读饮食模块，不照搬芽菜、带骨肉、内脏比其他食物普遍更优等结论。
- 1:57～3:48：以呼吸解释姿势稳定。适配时提醒用户在能呼吸的情况下保持躯干稳定；不要求整组一口气，也不把姿势控制等同于完整的呼吸功能评估。
- 3:49～6:52：谈感觉输入、触觉、视觉与肌肉发展。可以借鉴简单自查与反馈的组织方式，不承诺看或摸肌肉就能改变天赋、增长速度或神经功能；不默认脱衣训练、闭眼负重、痛觉刺激或发热膏。
- 本条属于训练思路参考，不提供动作教程链接，不单独开“神经激活治疗”模块。

## 训练计划、侧重点与休息（补齐原候选27）

[BV1EfxK67E3g](https://www.bilibili.com/video/BV1EfxK67E3g/)，22:28；用户提供本人B站入口，UID 521903482。已用机器转写＋关键画面对照。

0:30～5:35以胸配二头或三头说明协同肌间接训练量；5:37～10:30讨论背部与手臂组合；10:34～13:12讨论肩腿侧重点；13:13～18:52用自己的目标演示怎样调整组合；18:52～22:27讨论休息与有氧。

项目可用的意思是：推胸已经带到三头，拉背也带到二头，不能只算孤立动作；想优先练某个部位，也要给它安排合适的精力和恢复。视频把复合动作暂算成协同肌半组，是便于解释的粗估，不能用来精确计算每个人的有效组。分化名称不比实际执行重要，但仍要有基本覆盖、记录和调整规则。

不采用“推一定比夹增肌更快”“容量决定刻度、强度决定肉量”“有氧只会提高恢复、任何情况下都不掉肌肉”等绝对结论。休息日可以轻活动，也可以按状态充分休息，不强制高次数力量、爬楼或打球。具体组量、强度和每组休息继续依据用户时间与恢复安排，不照抄片中12组胸加4组手臂。

## 增肌减脂与长期进步（原候选28的同主题补充）

[训练进步如何做到最大化！！方法和心法！！](https://www.bilibili.com/video/BV14Enb6LEi2/)，19:52；本人发布，UID 521903482。已用机器转写＋关键画面对照。这是相关主题的后续讲解，片尾提及另一条增肌减脂视频；不能称为原抖音条目的同片替换。

0:34～2:12讨论了解饮食、训练表现和体型变化；2:43～9:34用不同体脂数字举例讨论减脂速度和维持；9:38～13:02把训练状态、饮食量与长期体型管理联系起来；13:03～16:02继续讨论兼顾目标和避免反复猛减猛吃；16:13～17:35谈普通人的生活安排，不必事事完美；18:39～19:46总结记录训练和饮食的目的。

可借鉴的是提问与反馈方式：体重之外，也看腰围、相似条件下的照片（用户自愿）、训练完成情况和恢复；做得到、能持续的安排优先。用户反馈精力、睡眠或训练表现持续变差时，重新检查饮食和训练负担。记录用于了解变化，不要求每顿拍照或每天填写长表。

不把“训练强度上升就一定增肌”“吃少了就不可能减脂”“某个体脂变化一定引起反弹”写成项目结论；力量进步也不能单独证明肌肉增长。不照抄竞技健美的低体脂目标、按体脂数字分阶段的时间表或‘一年几个月都在增肌’的效率计算。这些没有经本轮资料核对为普适处方，饮食热量、宏量营养与身体重组判断仍按本项目独立证据和用户反馈安排。

### 已接入训练安排（2026-11-05）

上述两条视频的思路已写进[训练编排规则](../training.md)，并同步到[每周三练示例](../example-gym-beginner.md)与[居家兼顾示例](../example-home-recomposition.md)：主项质量和渐进优先、协同肌负担纳入考虑、侧重点改变动作顺序、恢复决定是否加量或顺延、有氧按反馈调整、体重和腰围及训练状态一起回顾。具体剂量与触发条件属于项目实践规则，不说成视频原话。

独立证据复核：2026-11-05查阅[ACSM训练建议](https://acsm.org/resistance-training-guidelines-update-2026/)、[能量不足与阻力训练荟萃分析](https://pubmed.ncbi.nlm.nih.gov/34623696/)及[并行训练荟萃分析](https://pubmed.ncbi.nlm.nih.gov/34757594/)。采用个体化配量、避免把力量增长等同肌肉增长、合理兼顾有氧的方向；不把组间研究均值或元回归估计的热量数值变成每个人的固定阈值，也不保证休息日有氧一定加快恢复。

## 上肢功能与多平面训练（补齐原候选31主题）

[BV1CAaR6rECN](https://www.bilibili.com/video/BV1CAaR6rECN/)，20:54；本人发布，UID 521903482。标题“希望对大家有所帮助！！”较笼统，实际开场明确是上肢功能训练，已用机器转写＋关键画面对照。

| 片段 | 实际内容 | 在项目中的处理 |
|---|---|---|
| 0:10～2:12 | 弹力带活动，提醒不顶肚子 | 轻张力、舒适范围可参考；不照搬‘某方向必然磨损’的机制解释，不强求绕肩 |
| 2:13～3:01 | 毛毛虫手走到支撑位再返回 | 属于有一定支撑与核心要求的准备版本，不是每个新手必做，也不要求越远越好 |
| 3:04～7:27 | 龙门架低到高、水平、高到低的旋转模式 | 进阶选项；不把快速负重旋转连续组合自动安排给初学者 |
| 7:29～10:40 | 胸托坐姿器械划船，对握，示范肩胛后缩和调座高度 | 有对应基本动作教学；采用胸贴稳、不用腰甩的执行提示，先轻负荷试设置 |
| 10:43～13:21 | 交替哑铃卧推，强调躯干对抗 | 单独版本；不是双手同步上斜卧推的直接教程，不默认给新手增加难度 |
| 13:28～15:37 | 支撑交替哑铃划船、单手站姿推举 | 需额外支撑、平衡和取放控制；留作条件合适时的备选，不作基础通关要求 |
| 15:55～18:17 | 绳索弯举与下压的手臂组合 | 可选辅助，不复制半握要求或高负荷优先的说法 |
| 18:18～19:27 | 跑走间歇，约跑1分钟、走1.5～2分钟，4轮 | 单独评估运动基础与时间；不默认力量后必须加间歇跑 |
| 19:30～20:54 | 总结上下肢两次循环，功能、力量、心肺都可作为目标 | 接入目标分支；不宣称整套对所有人更健康或能治疗身体不适 |

教学可以关注身体能否稳定完成任务，不强迫每个人追求强烈的单块肌肉感觉。肩胛活动与推拉力量可作为训练内容，但不能从‘肩不舒服’直接诊断肩胛后缩不足，也不承诺先划船就能解决推胸疼痛。原片的超级组、约14～17组和间歇跑是作者这套示范的组合，不照抄成新手一小时计划。
