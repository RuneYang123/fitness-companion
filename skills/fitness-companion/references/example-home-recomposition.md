# 减脂增肌兼顾 · 居家示例

编写备注（不输出给训练用户）：本页演示编排形式，动作和训练量仍按当前用户条件调整。实际回复须从[教学索引](teaching-index.md)选匹配视频并另起一行；未匹配的给明确标注的通用B站搜索入口，不直接照搬缺少视频入口的示例表。

虚构展示：已规律训练、熟悉动作且无相关限制的成年人，有一对可调哑铃和垫子。具体需按个人调整，遵循[共用规则](writing.md)。

按“推→拉→腿→休息”一直往下练。推、拉日大约45～65分钟，腿日60～75分钟；先练力量，有氧看当天状态安排。

**无热身不训练，无激活不训练。** 先按当天内容活动关节，下面写了具体动作和次数；从小幅度开始，舒服地做，不硬扳。

| 当天 | 具体准备 |
|---|---|
| 推 | 手臂前后绕环各8次、屈伸手肘8次、手腕轻柔绕环每方向8次，墙壁俯卧撑8次 |
| 拉 | 双臂前伸收回8次、屈伸手肘8次、手腕轻柔绕环每方向8次，徒手髋铰链8次 |
| 腿 | 扶稳踝关节前移每侧8次、徒手深蹲8次、徒手髋铰链8次 |

表内第1项是激活准备，不计正式组，也不练累。确认哑铃锁紧、支撑稳固；卧推选能安全拿起和放回的重量。推肩前轻重量5次、飞鸟前极轻重量5次、硬拉前轻重量6次、分腿蹲前徒手每侧3～5次；按工作重量适当增加准备。

**训练清单：** 卧推、推肩、划船、深蹲、硬拉和分腿蹲，组间休息2～3分钟，其他动作60～90秒。重量选到这组做完，动作不变形还能再做2～3次。

| 推日 | 组×次数 | 提示 |
|---|---|---|
| 1. 激活：轻重量地板卧推 | 很轻8次，稍加重量5次 | 先试好拿起、推回和放下，不练累 |
| 2. 哑铃地板卧推 | 3×8～12 | 脚踩稳，上臂轻触地面不反弹 |
| 3. 站姿哑铃推肩 | 2×8～12 | 身体稳住，不挺腰顶重量 |
| 4. 哑铃侧平举 | 2×12～20 | 轻重量慢慢展开，不甩 |

| 拉日 | 组×次数 | 提示 |
|---|---|---|
| 1. 激活：轻重量单臂划船 | 每侧8次，需要时稍加重量5次 | 先找到稳定支撑，身体不跟着扭 |
| 2. 单臂哑铃划船 | 3×每侧8～12 | 分腿站稳、空手撑前侧大腿，拉时不扭身 |
| 3. 俯身哑铃反向飞鸟 | 2×12～20 | 屁股向后稳住，轻重量打开 |
| 4. 哑铃锤式弯举 | 2×10～15 | 手腕中立，控制放下 |

| 腿日 | 组×次数 | 提示 |
|---|---|---|
| 1. 激活：轻重量高脚杯深蹲 | 8次，需要时稍加重量5次 | 全脚掌踩稳，先把动作做顺 |
| 2. 哑铃高脚杯深蹲 | 3×8～12 | 哑铃靠近胸前，全脚掌稳住 |
| 3. 哑铃罗马尼亚硬拉 | 3×8～12 | 膝微弯，屁股向后找墙 |
| 4. 原地分腿蹲 | 2×每侧8～12 | 双脚前后分开，别站成一条直线，稳稳蹲下站起 |
| 5. 有支撑的双脚提踵 | 2×12～20 | 抬起再慢慢放下 |
| 6. 死虫式 | 2×每侧6～10 | 躯干稳住，慢慢伸手腿并呼吸 |

推日快走15分钟、拉日20分钟，参考“能交谈但不容易唱歌”；腿日按状态轻松走10分钟，累时省略。末尾慢下来约3分钟。休息日不补量。

这些有氧是可调整的起点。若明显影响下一次力量训练，先缩短、放轻或换时段；恢复不足就多休一天，休息日散步等轻活动可选。

**临时缺器械时：**
- 地板卧推可换合适高度的俯卧撑，先试3组×6～15次；支撑须稳固。
- 分腿蹲不稳可扶可靠支撑、改徒手，先保持动作控制。
- 划船可在有合适弹力带及可靠固定点时替换；没有可靠负荷就说明缺项。本例没有垂直拉设施，不拿抬臂等动作冒充下拉。

替换不追加，新动作先热身并重新选难度。更多替代用户需要时再给。

每组都能稳稳做到次数上限、还留点力气，下次再加最小一档重量。吃多少另外按你的情况安排，过一段时间一起看体重变化和训练状态；愿意的话也可以记腰围。练的时候如果疼、发麻或突然没力气，先停下这个动作。

体重暂时没降、腰围缩小且训练稳定时，先继续观察，不急着减食加练。连续几次越练越累、表现下滑，就先核对饮食、睡眠和训练量。推拉动作对手臂的负担也算在整体安排里，不自动把辅助动作继续叠上去。完整判断按[训练编排规则](training.md)。
